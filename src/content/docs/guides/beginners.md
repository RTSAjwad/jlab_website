Jlab's Beginner's Course is a free, anime-based course that teaches (almost) all
grammar and about 1000 words. You can download it from
[Ankiweb](https://ankiweb.net/shared/info/2110939339). There's a summary video on
[YouTube](https://www.youtube.com/watch?v=GHFcHfvgX5c).

Current version: **14**. You can also get update notifications by
[newsletter](/jlab_website/newsletter/).

- [Troubleshooting guide](/jlab_website/decks/troubleshooting/) for import and update issues.
- [Other decks](/jlab_website/decks/) created by Jlab.
- [Patreon](https://www.patreon.com/jlabjapanese) for supporting the
  project — thank you!

## Features

- Flashcard-based for maximum efficiency (ships as an Anki deck)
- Each flashcard introduces only a single new item (word or grammar)
- No prior knowledge required, in particular no reading skills
- Follows Tae Kim's grammar guide
- All example sentences are from real anime & dorama
- Audio and image included
- Minimal grammar explanations on the flashcards
- Works with the Jlab addon, which takes care of teaching the writing systems.
  Can also be used without it.
- Important lessons learned are on cards in between, taken from the learner's
  diary kept for about 5 years.

## Basic installation (Anki + jlab + Ankiweb + deck)

1. Install the PC version of Anki (**Qt6 branch — the addon does not support Qt5
   anymore**).
2. Install the Jlab addon (in Anki, go to **Tools → Addons → Get Addons**, then
   enter the following ID: `2110939339`).
3. Download and import the beginner course on your computer (after the addon is
   installed).
4. Optional: Install AnkiDroid or AnkiMobile.
5. Optional: Register a free account on Ankiweb to sync your progress across
   multiple devices.
6. Optional: Sync everything to your mobile device using Ankiweb.
7. For correct updating behavior, only import the new deck on your computer's
   Anki while having the Jlab addon installed.

## Minimal installation (Anki + deck, no Jlab addon)

1. Get Anki, AnkiDroid or AnkiMobile.
2. Download and import the Jlab beginner deck on your computer.
3. All further instructions are found inside the deck.
4. Without the addon, you need to take care of a few things yourself.
   [Read more here](/jlab_website/guides/course-without-addon/).

## Don't

Anki provides a lot of freedom, you can customize lots of things related to the
deck. **For proper updating however, don't do the following:**

- Shift, add or delete fields on the note.
- Rename the deck or move it into a subdeck.
- Delete one of the subdecks.

All of the above lead to problems when updating to a later version. The problems
can all be fixed, but this is fiddly and complicated. **Changing the card
template however is fine.**

## How to use the course

- The deck has two subdecks. Start with the listening comprehension deck, it
  contains a few extra cards.
- Try not to do more than 10 cards in the beginning (to avoid an avalanche of old
  cards).
- For card-specific questions / bug reports / complaints, use the question link
  on the card.
- Before asking a question, have a look at a few more cards — things are usually
  covered with more than one example.
- Try to focus on listening comprehension first, that's the easiest part. Don't
  try to recite/shadow the sentences.
- If you're not a total beginner, you may already understand some of the cards
  upon first sight. These ones should be suspended immediately (`@` or `!`).
- The reading deck should be done after the listening deck, but is absolutely not
  mandatory. It is only for practicing kana.
- Further instructions are found inside the deck.
